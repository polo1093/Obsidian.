## Vérification rapide

- [ ] Le compte se synchronise correctement.
- [ ] L’envoi et la réception fonctionnent.
- [ ] Les règles produisent le résultat attendu.
- [ ] Les catégories sont cohérentes.
- [ ] Les invitations contiennent toutes les informations nécessaires.
