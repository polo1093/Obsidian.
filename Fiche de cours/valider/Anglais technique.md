> **Objectif :** communiquer simplement avec un utilisateur anglophone et comprendre la documentation technique.

## Accueillir et préciser

| Français | Anglais professionnel |
| --- | --- |
| Comment puis-je vous aider? | How can I help you today? |
| Depuis quand le problème existe-t-il? | When did the issue start? |
| Quel message voyez-vous? | What exact message do you see? |
| Est-ce que cela touche d'autres personnes? | Is anyone else affected? |
| Qu'avez-vous déjà essayé? | What have you tried so far? |

## Guider une manipulation

- **Please open Settings.**
- **Select Network and Internet.**
- **Could you confirm the Wi-Fi icon is visible?**
- **Please do not restart the computer yet.**
- **Let me know when the window is open.**
- **I will explain each step before making a change.**

Utiliser des phrases courtes, un verbe d'action et une étape à la fois.

## Vérifier le résultat

- **Could you try the same action again?**
- **Do you still see the error?**
- **The connection is working now.**
- **I would like to monitor it for a few minutes.**
- **I will document what we changed.**
- **Please contact us again if the issue returns.**

## Messages de billet

~~~text
Issue: The user cannot connect to the shared printer.
Scope: One Windows 11 workstation is affected.
Checks: Network access and name resolution are working.
Action: The printer was removed and re-added using the approved driver.
Result: The user printed a test page successfully.
~~~

## Formulations prudentes

- **It may be related to...** : hypothèse;
- **The logs indicate...** : constat appuyé;
- **I need to verify...** : vérification nécessaire;
- **I will escalate the ticket...** : transfert structuré;
- **I cannot confirm the cause yet.** : honnêteté professionnelle.

Éviter **I think it is fixed**. Préférer **The test completed successfully, and the user confirmed the service is working.**

Un **pronom relatif** relie 2 idées et introduit une **proposition relative** pour préciser un nom.

## Les principaux pronoms relatifs (EN → FR + usage)

### **who** (personnes) → *qui*

* Sujet (souvent) / courant
* *The technician **who** helped me…* = Le technicien **qui** m’a aidé…

### **whom** (personnes, objet) → *que / à qui*

* Plus **formel**, surtout après une préposition
* *To **whom** did you speak?* = À **qui** avez-vous parlé ?
* En anglais courant, on remplace souvent par **who** : *Who did you speak to?*

### **whose** (possession) → *dont / duquel*

* Personnes **et** choses
* *The client **whose** account is blocked…* = Le client **dont** le compte est bloqué…

### **which** (choses / animaux) → *qui / lequel*

* Très courant après une **virgule** (info additionnelle)
* *The printer, **which** is new, is already broken.* = L’imprimante, **qui** est neuve, est déjà en panne.

### **that** (personnes ou choses) → *qui/que*

* Très fréquent en anglais “neutre” **sans virgule** (info essentielle)
* *The email **that** I sent…* = L’email **que** j’ai envoyé…

### **where** (lieu) → *où*

* *The office **where** I work…* = Le bureau **où** je travaille…

---

## Point clé : **virgule ou pas ?** 🧠

* **Sans virgule** = info **essentielle** (restrictive) → souvent **that / who / which**

  * *The file that you sent…* (c’est ce fichier précis)
* **Avec virgule** = info **bonus** (non-essentielle) → plutôt **which / who**, **pas that**

  * *The file, which you sent yesterday, …*

---

## Raccourci “bureau”

* Personne : **who**
* Objet/outil/fichier : **that** (souvent) ou **which**
* Possession : **whose**
* Lieu : **where**
* Très formel : **whom** (surtout après préposition)


would = politesse / atténuation (“We would like…”) ou hypothèse (“I would offer… if…”).

may = permission (May I…?) ou registre formel / rassurant (may rest assured).

might = possibilité (incertain → “Let me verify”).

must = déduction forte basée sur un indice (“hat covered with snow”).

can = capacité / possibilité concrète (“You can reach me…”).

will = intention / action à venir (“I will inform…”) ou promesse (“will not happen again”).

cannot = impossibilité (pas “refus”).

should have + Vpp = reproche / regret sur le passé (“should have remembered”).
