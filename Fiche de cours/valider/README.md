→ Déployer → Sécuriser → Documenter

## Principes communs

Toutes les fiches mettent l'accent sur :

- la protection des données;
- le moindre privilège;
- les changements réversibles;
- la validation avec l'utilisateur;
- la documentation exploitable;
- l'escalade au bon moment;
- la vérification des sources officielles.
